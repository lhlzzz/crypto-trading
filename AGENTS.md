# bian - Binance Market Data Bot

`bian` owns only public Binance crypto-market data.

- Database: `postgresql://bian:bian@localhost:5446/bian`
- Frontend: Financial OS `/dashboard/bian`
- Mode: `PUBLIC_READ_ONLY / NO_TRADE`

Never read Polymarket data, add orders or wallet access, or import code from
another bot workspace.
